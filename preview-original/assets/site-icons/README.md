# Navigation brand icons

Snapshots of the 13 brand favicons used by the published navigation, retrieved
from `https://favicon.im/<hostname>?larger=true` on 2026-10-16. Brand names and
artwork belong to their respective owners. These files identify links to those
websites; they do not imply affiliation.

`app.js` maps each hostname to its local asset. Explicit icons set in navigation
management still take priority. Personal project icons retain their existing
appearance. New, unlisted websites keep the existing remote favicon fallback.
