# React Bits Dock 本地验收 · 2026-10-16

采用官方 JavaScript/CSS 源码，保留原许可，无新增运行依赖。添加 Popover 包装入口和固定 ID 按钮引用，避免登录后插入随手记造成动画与键盘焦点错位。

在独立 18870 服务、独立测试账号与测试便笺上实测：

- 登录前只有音乐／日历；登录后显示音乐／随手记／日历。退出立即卸载私人便笺入口和模块，剩余工具正常工作。
- 音乐：导入本地测试 WAV，实际播放、收起后保持播放、重新打开暂停。歌曲未上传，刷新歌单仍按原规则清空。
- 随手记：输入测试文字、切换勾选清单、等待自动保存，刷新后保留内容；没有触碰实际站主的便笺或密码。
- 日历向上展开，Escape 关闭并返回按钮。Dock 左右箭头、Home/End、Enter 已验证，包括登录／退出后动态增减入口的顺序。
- 真实鼠标进入 Dock 后，按钮宽度从基础 42px 连续增大，邻近按钮一起响应；点击保留回弹。系统减少动态效果沿用上游实现，未切换操作系统偏好实测。
- 深浅主题均在 1920×1080 完整显示 24 张测试卡片、Dock 和页脚；页面 scrollWidth/scrollHeight 为 1920×1080。Dock 正常占位，基础尺寸 176×60px，位置 y=956–1016，网格底部 y=842，页脚底部 y=1080。

## 悬停稳定性修正

用户反馈进入时有抖动感。原底座随按钮尺寸从 176px 持续变宽；现为三项工具固定 212px、两项固定 142px，并固定上沿感应区。图标放大上限由 58px 收敛至 54px，弹簧参数改为 mass=.18、stiffness=210、damping=14，保留点击回弹。上方旧验收中的 176px／58px 为修改前数据；高度、页面占位和权限逻辑未变。

真实浏览器点击底座空白处模拟鼠标进入，连续采样 24 次：底座始终 212px，中心按钮从约 43.55px 单调趋近 54px；停留上沿连续采样 12 次保持 hover=true、宽 212px、中心按钮约 53.98px，未见反复进入／退出。离开、音乐弹层与 Escape 返回继续通过。构建退出码 0。未修改导航数据、便笺或密码。
