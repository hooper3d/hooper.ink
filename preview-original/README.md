预览地址：http://127.0.0.1:18869/ 。仅绑定本机，无需构建或安装依赖。

顶栏预构建资源已包含在 `ui/`。修改顶栏源码前运行 `npm.cmd ci --prefix preview-original` 安装锁定的 Howler 依赖，再运行 `node preview-original/build.mjs`；其余构建依赖复用已安装的 `preview-1080/node_modules`，不修改此前 Demo。天气与日历的本轮验收见 [2026-10-16 更新](#2026-10-16-交互与顶栏更新)。

从仓库根目录启动：`node preview-original/serve.cjs`。原站 18866、React Flow 深浅两版 18867 及配色样例 18868 保留。本目录独立运行，不替换 `public/index.html`，不修改线上。

### 本地后台预览

首次安装并启动：`powershell.exe -NoProfile -File scripts/local-preview.ps1 -Install`。Windows 计划任务 `Hooper-Navi-Preview` 使用当前用户的普通权限，在登录 Windows 时自动运行，不依赖开发终端。仅监听 `127.0.0.1:18869`，沿用 `preview-original/.local` 数据。

后台启动器明确开启本机免登录，直接显示头像、管理入口和 Dock，不改写密码或登录会话文件，写入仍验证来源及 CSRF。普通 `node preview-original/serve.cjs` 启动继续要求登录；生产模式拒绝开启免登录。本机免登录只接受回环地址连接及匹配的 localhost / 127.0.0.1 主机头。

预览进程退出后 5 秒自动重启；托管脚本异常退出由计划任务间隔 1 分钟重试。日志在 `preview-original/.local/runtime/`：`supervisor.log` 记录启动、退出码和重启，`stdout.log` / `stderr.log` 记录程序输出。程序每次重启保留前三份输出日志；托管日志超过 1 MB 时轮换，运行状态保存在 `state.json`。这些文件不提交 Git。

查看状态：`Get-ScheduledTask -TaskName Hooper-Navi-Preview`。手动停止：`Stop-ScheduledTask -TaskName Hooper-Navi-Preview`；再次启动：`Start-ScheduledTask -TaskName Hooper-Navi-Preview`。电脑关机或用户注销后不继续运行，下次登录 Windows 自动启动。本地托管不修改线上部署。

品牌字样 `Hooper Navi` 已将 Proxima Nova ExtraBold Italic 转为独立 SVG 路径：`assets/hooper-navi-wordmark.svg`（约 3 KB）。保留原字距和约 101×22px 尺寸，随标题字号响应缩放，使用 CSS 遮罩跟随深浅主题颜色。SVG 无字体、文字节点或外部资源依赖，不再调用本机字体，也没有把原字体文件复制到仓库。原图标仍为 24×24，其余页面字体保持不变；标题和首页链接保留无障碍名称。

## 本地音乐试用

搜索框现默认 Google，回车或右侧搜索按钮在新标签打开结果；普通输入不再过滤导航卡片。左侧可切到「本站」，恢复实时筛选及回车定位首个结果。空关键词不会打开空结果页，Escape 清空、`/` 和 Ctrl/Cmd+K 聚焦继续可用，原 `!g` 等搜索前缀保留；每次加载默认回到 Google。

音乐、随手记、日历的入口已移至底部 React Bits Dock，点击向上展开；顶栏保留天气、日期摘要、主题及最右侧头像。未登录时不渲染随手记按钮和模块。Dock 保留连续放大、点击回弹、悬停标签和当前工具圆点，使用网站深浅主题。支持左右箭头、Home/End 切换工具，Enter/空格展开，Escape 关闭浮层并返回按钮。布局正常占位，预留放大空间。源码及原许可在 `src/vendor/react-bits-dock/`，构建后许可为 `ui/react-bits-dock-license.txt`。验收见 [Dock 验收](dock-qa.md)。下方原有功能说明中的顶栏入口现均指 Dock。

顶栏音符打开 Howler.js 2.2.4 迷你播放器，选择或拖入常见音频文件，支持多选、歌单切换、播放／暂停、进度、音量、静音、列表循环与单曲循环。右上角垃圾桶可在确认后清空全部本地和在线曲目，同时停止播放并保存空列表；不删除电脑原文件，保留音量与循环偏好。收起浮层仍继续播放；跟随网站深浅主题，首页没有新增常驻卡片或侧栏。

歌曲和歌单顺序保存在当前浏览器 IndexedDB（`hooper-music`）中，不上传、不写入导航数据。刷新后恢复文件并重新生成 Blob URL，停在第一首，点击播放；添加、去重、移除会自动保存，音量偏好仍单独保存。底部显示恢复／保存状态，失败可重试，保存中刷新会提醒；恢复失败时禁止覆盖原歌单。旧版临时歌曲需重新导入一次。清理站点数据或更换浏览器／地址后无法沿用，不作为文件备份。不同格式仍取决于浏览器解码能力；移除歌曲或页面销毁时释放音频实例与 Blob URL。Howler 的 MIT 许可随构建保存在 `ui/howler-license.txt`。

播放器右上角云朵按钮可导入网易云公开歌单，支持完整歌单链接或数字 ID，暂不支持分享短链接。合并到已有列表并去重，总容量仍为 100 首；在线曲目只保存歌曲 ID 与名称等信息，播放时重新获取地址，不下载到浏览器曲库。歌单导入是一次快照，更新需重新导入；不跨设备同步。接口 `/api/music/playlist` 和 `/api/music/track` 均需本站登录，仅请求固定网易云接口，不接受任意远程音源网址，也不代理音频流量。音频由浏览器直接从网易云 HTTPS 地址播放，遇到平台权限、地区或接口变化时可能不可播放；上游返回试听地址时标注「试听」。不接入网易云账户或会员凭据。部署需同时包含 `music-source.cjs`。

## 私人随手记

顶栏品牌已改为 **Hooper Navi**。登录现有管理账号后，顶栏才出现随手记入口；没有新增密码或重置现有密码。随手记使用 Tiptap 3.31.4，编辑后约 700ms 自动保存，顶部对勾／圆点／旋转图标表示保存状态。支持文字、自动识别 HTTP(S) 链接、简单加粗、撤销重做，以及选择／粘贴／拖入图片；图片以紧凑附件展示，可点缩略图预览或保存。

底部仅保留加粗、清单、链接、附件四个图标。清单可将当前段落变为复选项，支持勾选／取消、回车继续下一项及空项回车退出；完成项以灰色删除线显示，状态一起自动保存。撤销／重做保留 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 快捷键，不再占用常驻按钮。保存失败时显示重试，版本冲突时才显示重新载入。

便笺保存在 `.local/notes.json`，覆盖前留一份 `.bak`；图片保存在 `.local/note-images/`。正文和图片读取都要求有效管理会话，写入还检查来源和 CSRF；未登录返回 401，不通过公开导航接口或静态目录暴露。退出登录后编辑器和入口卸载；会话状态每 30 秒及窗口恢复焦点时重新检查。内容不存浏览器 localStorage，不接入第三方同步。

图片限 PNG／JPEG／GIF／WebP、单张 8 MB，总图片存储 100 MB，服务端检查文件签名。移除附件不立即删除原文件，以支持撤销与上一版备份；这些文件仍需登录访问。保存失败会显示错误和重试；较旧版本返回冲突，重新载入前提醒放弃未保存修改。未保存／上传期间刷新有浏览器提醒，退出登录也会提示。当前为一份连续便笺；没有新增多本笔记、公开分享或在线协作。

验收见 [私人随手记](notes-qa.md)。MIT 许可随构建保存于 `ui/tiptap-license.txt`。仍仅在 18869 本地预览，不替换线上。

## 导航管理

右上角「登录」打开密码窗口；登录后显示站主头像，点击头像菜单可进入「导航管理」或「退出登录」。登录不会自动打开管理面板。沿用已有密码；仅未初始化时由站主设置至少 10 位密码，没有预设密码，也不需要把密码发给开发助手。

- 管理网站名称、网址、说明、分类、搜索别名、自定义图标和首页隐藏。
- 支持网站拖动／上下排序、分类新增／重命名／排序／删除、删除撤销、JSON 导入导出。
- 网站／分类编辑点「保存」即写入服务并同步首页，无需再次提交。列表排序、删除及导入先更新草稿，底部「保存全部」统一提交，提交前可撤销。保存成功显示「已保存」；失败保留编辑内容。已有列表草稿会随编辑保存一起提交。未提交的列表修改有圆点提示，刷新会出现浏览器提醒；关闭面板保留当前草稿。
- 「图标网址」旁可上传 PNG／JPEG／GIF／WebP／ICO，单张最大 2 MB，上传后自动填入本站地址并预览；在编辑窗口点「保存」即可应用到首页。文件保存在 `.local/site-icons/`，总量上限 100 MB，图片可公开读取，上传验证登录、来源和 CSRF。更换或取消不会立即清理旧图，以保留撤销和备份引用；JSON 导出只含图片地址，备份时需同时保留图标文件夹。
- 登录后头像菜单的「更换头像」上传后立即保存，同步右上角和公开 About 名片；头像引用存于 `.local/profile.json`，图片沿用 `site-icons/` 存储及上传限制。备份需保留这两处，公开读取头像资料，修改仍需登录、来源和 CSRF 验证。
- 首页固定最多 24 个可见入口，新增时容量已满会默认隐藏；先隐藏其他入口再显示即可。管理库最多 500 条，分类多于 5 个时收进更多菜单，不挤出首页。
- 用户输入经过前后端校验与页面转义；只接受 HTTP／HTTPS、站内路径及原有小程序占位链接。分类有网站时须先移动网站才能删除。
- 导出只含导航数据，不含密码、会话或浏览器个人收藏。导入先进入草稿，检查后再保存。

数据写入 `preview-original/.local/navigation.json`，保存前留一份 `.bak`；重启服务、换浏览器后仍可读到修改。密码只保存随机盐和 scrypt 哈希，位于 `.local/auth.json`；这些路径被忽略，不对静态访问开放。站主会话为 8 小时，使用 HttpOnly、SameSite=Strict Cookie；保存接口验证登录、来源和 CSRF 凭据，并拒绝旧版本覆盖新内容。

**当前仍为仅本机的 HTTP 预览服务。** 正式部署前需配置生产域名、HTTPS／Secure Cookie 和运行数据备份；没有部署到线上。浏览器收藏仍沿用原 `nav_favs`，与公开导航数据分开。

验证见 [管理系统验收](management-qa.md)。实际预览的密码尚未由助手设置，原有 24 条导航数据也未被测试改写。
