# 本地音乐播放器验收 · 2026-10-16

仅改动 18869 独立预览；没有更改线上、public 原站或 18867 的 Demo 源码。Howler 2.2.4 由 npm 锁定，构建复用原有工具；许可一并保留。

## 实测

以下原始验收为临时歌单版本；最新持久化验收见文末。

- 通过真实文件选择器多选两首自主生成的 30 秒 WAV 验收音频，自动开始第一首，时长、进度与选中项正确。
- 暂停、恢复、进度键盘调节、上一首／下一首、静音／取消静音可用。收起后顶栏仍显示播放状态，重新打开进度继续。
- 单曲循环到末尾仍停留同一首且进度重新前进；列表模式播放到末尾切到下一首。
- 移除当前曲目、移除最后一首后回到选择入口；验收结束已清空测试歌单，没有导入站主的私人歌曲。
- 深浅主题可用；1920×1080 首页为 24 条，页面尺寸 1920×1080，无页面滚动。390px 窄屏浮层在可视宽度内，不被左边缘裁切。
- 浏览器验收流程未观察到控制台 error 或 warn。

## 边界

歌曲是用户明确选择后生成的本机 Blob URL，不上传到服务器。刷新后不保留歌单，音量偏好单独保存在当前浏览器。没有公开歌单、在线搜索、音乐站 API 或图片封面解析。本轮使用 WAV 验证了实际播放，未逐一实测 MP3／FLAC 等格式；其余格式支持受浏览器解码能力影响。拖入功能已实现，但未自动操作系统文件拖放；真实文件选择器路径已实测。

截图位于 `evidence/music-20261016/`。含 music-check 文件名的截图是合成音频测试状态；`ready-dark-1080.jpg` 是已清空验收歌单、等待站主选择文件的最终页面。

## 歌单持久化更新

2026-10-16，仍仅修改本地预览。浏览器 IndexedDB 保存完整音频 File 与歌单顺序，刷新后重新生成 Blob URL，恢复到暂停状态。读写事务成功后才显示保存完成；写入串行，最新快照完成前保留保存中状态。存储空间不足或其他读写错误显示重试，读取失败时禁用添加，避免空歌单覆盖已有数据；未做空间不足／拒绝存储的故障注入。

在独立 18870 测试域使用两首合成 WAV 实测：导入两首→保存→刷新仍有两首且顺序不变→点击播放成功→下一首成功→暂停→移除第一首→刷新只剩第二首→重新导入两首（重复项不增加）→刷新为 B、A 的新顺序。移除最后两项并刷新后为空歌单。没有导入或修改站主歌曲，没有刷新站主原页面。

截图 `evidence/music-persistence-20261016/restored-playlist.jpg` 为刷新后恢复的两首测试歌曲。构建退出码 0。此更新未改动页面布局、Dock、登录、导航与便笺；仅保存在当前浏览器、当前站点，清理站点数据会删除歌单及音频。旧页面未保存的临时歌曲不能自动迁移，需首次重新选择。
