# Hooper Navigation · 1080p 布局预览

基于原 `hooper-nav-v2` Demo 的独立本地预览，使用 React Flow、Ant Design、Tiptap、Meteocons；不修改原 Demo 的源码和浏览器内容，也不替换正式站。

## 运行

在本目录执行：

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run build
npm.cmd start
```

打开 `http://127.0.0.1:18867/`。服务仅监听本机，提供 `dist` 静态文件；修改源码后需要重新构建和刷新。

## 本轮范围

- 无侧栏，保留品牌名片、诗词、天气、日历和随手记组件；原有工具图标集中在顶部右侧，未更换图标库或网站图标。
- 页头品牌标记使用用户提供的 `assets/hooper.svg` 原始矢量形状，通过蒙版继承网站正文色：深色 `#E6E9ED`、浅色 `#263750`；原 SVG 文件保留，不修改源图形或其路径。
- 已按选定的第一版「无框工作台」实现：去掉组件大外框与填充底色，用两条细竖线分列；只有搜索框、浮层和悬停中的网址使用表面色。
- 标准 1080p 下正文使用系统无衬线字体，随手记正文 18px、网址标题 18px、说明 15px、区域标题 24px；诗词保留衬线字体。较矮或较窄窗口使用紧凑排版。
- 网址悬停／聚焦显示主题对应底色和打开提示，收藏提供按下状态，点击有轻微位移反馈；交互过渡为 100–140ms，遵循系统减少动态效果偏好。GitHub 原图标仅在深色下做单色明度适配，浅色恢复原图，未更换图标资产。
- 应用已选定的深石墨：背景 `#141516`、卡片 `#222426`、悬停 `#2C2F32`、边界 `#3D4248`、正文 `#E6E9ED`、次级文字 `#AAB2BC`、强调 `#CED5DF`。采用实色表面，移除点阵与玻璃效果；顶部配色入口展示当前色板。
- 新增参照原站的浅色：背景 `#F1F5FB`、表面 `#F8FAFD`、悬停 `#E4ECF7`、边界 `#C9D5E5`、正文 `#263750`、次级文字 `#5C6F89`、强调 `#356AB1`。保留无框三列布局，不引入原站卡片、点阵、滚动或纯黑／纯白主色。
- 导航数据取自正式站 24 个条目；原站相对链接转为正式站绝对链接，避免从预览误跳到不存在的本地页面。
- 一屏视野固定为 100%，不使用整体缩小或平移来藏放组件；不同视口按组件区域重新计算位置和尺寸。
- 网址区域在标准桌面尺寸使用 4 列、6 行，导航居中，随手记在左侧，天气和日历在右侧；没有导航翻页或内容区内部滚动。
- 上下区域共用三列边界：头像与随手记对齐，搜索和诗词与中间导航对齐，天气与右侧日历对齐。
- 随手记使用专门的示例文字、链接和图片附件，未导入用户真实内容。
- 搜索、分类、当前浏览器收藏、色板查看、日历与图片查看可用。
- `/` 或 `Ctrl/⌘ K` 定位搜索，输入即时筛选，Escape 清空，回车或搜索按钮聚焦首个结果；首页按钮同时重置搜索与分类。
- 本轮为只读布局预览：未开放网站、随手记和布局编辑，没有新增写入 API。密码登录和服务器内容保存未在此预览实现。
- 默认深石墨，右上角「配色」内可切换「深石墨／原站浅色」。选择保存在本预览的 `hooper-preview-appearance`，刷新恢复，不重置搜索、分类或内容状态。主题及收藏均使用本预览 origin 的浏览器存储，和 54894 原 Demo、18866 原站预览互不相通。
