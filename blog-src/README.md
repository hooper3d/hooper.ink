# Hooper 博客

保持静态博客：Markdown 正文 → Python 构建 → `public/blog/`。不需要数据库、网页编辑器或前端框架。

## 写作与构建

由 Ray 整理文章时，编辑 `posts/*.md`，不要直接修改生成的 HTML。现有文章的 `slug` 是公开链接，不随标题调整而变化。

```yaml
---
title: 文章标题
date: 2026-10-22
slug: article-slug
summary: 一两句话概括文章内容。
tags: [开发, 实践]
---

文章正文。
```

`title`、`date` 必填，`slug` 默认使用文件名；`summary`、`tags`、`cover` 可省略。页面不展示装饰性封面，历史 `cover` 仅保留为分享预览图。历史正文图片保存在 `images/`，构建时保留原有相对路径；新增正文图片也可放在此目录，以 `../images/文件名` 引用。正文图片自动延迟加载。不填写不存在的占位图片。`read_time` 可指定正整数，否则按正文估算。

需要 Python 3.10 或更新版本。首次安装依赖，之后运行构建即可；命令不依赖当前目录，以下以仓库根目录为例：

```powershell
python -m pip install -r blog-src/requirements.txt
python blog-src/build.py
```

成功时退出码为 0，生成文章列表、文章和本地资源。重复 slug、无效日期、缺失标题或封面会中止构建，返回非零退出码，修复后重新运行。目录、代码高亮、前后篇导航均在构建时完成，阅读不依赖浏览器脚本。

构建后可用本机静态服务查看：

```powershell
python -m http.server 18872 --bind 127.0.0.1 --directory public
```

预览地址为 `http://127.0.0.1:18872/blog/`。也支持 `python blog-src/build.py --output <独立输出目录>`，供构建核对使用。

## 风格与交互

- 配色直接读取 `preview-original/style.css` 中的 Hooper Navi 主题，品牌图标也从主站复制。主站更新配色后，重新构建博客即可同步。
- 页面使用本地 CSS、少量原生 JavaScript 和系统字体回退；不加载 Tailwind CDN、图标字体、在线字体或浏览器代码高亮库。
- 首页采用内容概览、标签筛选和按时间排列的纯文字列表，不展示配图或精选卡片。概览数字由现有文章计算，不虚构分类或阅读量。
- 标签统一为 AI Agent、AI 创作、开发实践三个主题，每篇使用 1–2 个，避免把技术名词和写作形式都变成标签。筛选状态写入 `?tag=标签`，可复制链接，并支持浏览器前进、后退和刷新恢复；无 JavaScript 时直接显示完整文章列表。
- 正文、目录、列表无需 JavaScript 即可显示。脚本只增强主题切换、目录当前位置和按需评论。
- 深浅主题使用主站相同的 `theme` 偏好，并响应同一来源下其他标签页的主题切换。
- Giscus 保留原仓库与 pathname 映射，在读者点击“加载评论”后加载；失败可以重试，也可直接打开 GitHub Discussions。
- 不蒜子阅读数保留为可选配置，仅在 canonical 指定的正式来源加载，避免本地预览污染统计；加载失败不显示空占位。

站名、简介、分享图和第三方服务配置位于 `blog.config.yaml`。文章使用原路径 `/blog/posts/<slug>.html`，保留已有访问链接和评论对应关系。

## 发布约定

本地构建与预览不等于发布。用户明确要求上线后，再进行提交和部署。

1. 核对服务器 `blog-src/posts/` 是否有比本地更新的文章，保留历史正文和 slug。
2. 构建后确认所有文章、目录锚点、封面、前后篇链接正常，并检查手机与深浅主题。
3. 发布前备份服务器的 `blog-src/` 和 `public/blog/`，记录提交；只更新这两个博客目录，不改首页服务、私人数据或其他站点。
4. 同步博客源文件与生成文件，保留备份；验证线上首页、文章和资源。若删除或改名文章，应明确处理旧链接，不能仅删除线上页面。
5. 需要回退时恢复本次博客备份。Nginx 现有 `/blog/` 静态路径继续使用，不需要重启主站服务。
