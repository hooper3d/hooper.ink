# 今日 AI 圈 Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 在 hooper.ink/ai-daily 创建一个 AI 资讯聚合页面，自动抓取多个 RSS 源，生成静态 JSON，前端展示为卡片式信息流。

**Architecture:** Node.js 脚本定时抓取 RSS → 解析 → 过滤 AI 相关 → 写入 JSON → 静态 HTML 页面加载 JSON 渲染。配色与导航站联动（电光蓝 #3b82f6 主题）。

**Tech Stack:** Node.js (内置 http/fetch), rss-parser (npm), 静态 HTML + Tailwind CDN + Chart.js
